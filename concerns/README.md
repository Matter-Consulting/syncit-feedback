# Concerns, comments and suggestions

One file per concern, comment or suggestion a maintainer has looked at, named after its
GitHub issue: `0018-the-chat-changed-a-file-without-saying.md`. Newest last, so the folder
reads as the history.

A file is written when the item is decided (acted on, planned, a question back, or declined)
and updated when that changes. Its front matter: `id` (the file's name), `issue` (the GitHub
number), `kind: concern`, `area`, `title`, `version`, `date`, `status` (open, planned,
waiting, fixed, answered or declined), `closed`, `resolution` (what was done, the TODO heading
it was planned under, or why not). Then the concern, the decision, the links. The whole shape,
and who writes it: [`../TRIAGE.md`](../TRIAGE.md).

To raise one: [`../README.md`](../README.md).
