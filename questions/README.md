# Questions

One file per question a maintainer has answered, named after its GitHub issue:
`0016-how-do-i-add-a-storey.md`. Read together they are a list of answers to the questions
engineers really ask, and the user guide grows from them.

A file is written when the question is answered (or asked back, or declined) and updated when
that changes. Its front matter: `id` (the file's name), `issue` (the GitHub number),
`kind: question`, `area`, `title`, `version`, `date`, `status` (open, waiting, answered or
declined), `closed`, `resolution` (`answered`, or the user guide page the answer went into).
Then the question, the answer, the links. The whole shape, and who writes it:
[`../TRIAGE.md`](../TRIAGE.md).

To ask a question: [`../README.md`](../README.md) (the chat in SYNCIT answers most at once).
